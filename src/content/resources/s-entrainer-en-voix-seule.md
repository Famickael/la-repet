Vous pouvez vous entraîner en voix seule, sans caméra, dans La Répét’. Ce mode vous laisse écouter votre entretien et, si vous avez activé le retour de l’assistant, lire les repères disponibles. Il peut vous convenir pour travailler une explication ou préparer un entretien téléphonique.

## Choisir une question à travailler

Ouvrez votre espace, puis rendez-vous dans le choix des questions. Vous pouvez sélectionner une seule question pour commencer. Si vous en choisissez plusieurs, vous pourrez avancer dans la série après avoir traité la question en cours. Le bouton « Commencer (1 question) » affiche le nombre sélectionné et vous mène à l’écran de réponse.

Prenez quelques instants pour décider ce que vous souhaitez expliquer. Vous pouvez retenir le contexte, l’action que vous voulez décrire et ce qui s’est passé ensuite. Pour préparer vos exemples, le guide [Parler de ses expériences avec la méthode situation, action, résultat](#/ressources/parler-de-ses-experiences-methode-sar) propose une trame. Si vous préférez vous concentrer sur le son, choisissez une question que vous connaissez déjà et essayez de dire votre réponse une fois sans lire.

## Autoriser le micro et lancer l’enregistrement

Dans l’écran de réponse, choisissez « Voix seule ». Si le navigateur affiche une demande d’accès au micro, autorisez-le pour enregistrer. Vous pouvez faire cet essai dans un endroit où votre voix se distingue du bruit autour de vous. Si vous utilisez des écouteurs avec micro, vérifiez qu’ils sont branchés ou connectés avant de commencer.

Quand vous voulez, sélectionnez « Démarrer l’enregistrement ». Répondez à la question, puis utilisez « Arrêter l’enregistrement » lorsque vous avez terminé. La réponse dure 3 minutes au plus. Vous pouvez arrêter plus tôt si vous avez terminé votre exemple. Gardez le navigateur ouvert pendant l’enregistrement.

> [!conseil] Tester une courte réponse
> Pour faire un essai de micro, vous pouvez dire une première phrase, arrêter puis écouter ce qui a été capté. Si la voix arrive faiblement, rapprochez le micro ou changez de place avant de recommencer.

Si le micro ne s’ouvre pas, vérifiez les autorisations du site dans le navigateur et le périphérique sélectionné sur votre appareil. Vous pouvez aussi fermer une autre application qui utilise le micro, puis retourner à l’écran de réponse. Si vos écouteurs se déconnectent, vérifiez le son de l’appareil avant de reprendre.

## Écouter avant de décider quoi garder

Une fois l’enregistrement arrêté, utilisez le lecteur pour vérifier votre réponse. Vous pouvez écouter le début, attendre la fin d’une phrase ou reprendre un passage. Vérifiez que votre voix est audible et que l’exemple permet de comprendre votre action. Vous pourrez ensuite décider si vous gardez cet entretien ou si vous préférez un autre essai.

Le bouton « Recommencer » vous permet de refaire l’enregistrement. Si vous avez activé le retour de l’assistant, choisissez « Voir mon retour » pour conserver l'entretien et demander ce retour. Si vous vous entraînez sans ce retour, le bouton est « Garder cet entretien ». Vous pouvez retrouver les entretiens gardés dans votre espace.

> [!exemple] Vérifier que votre action est compréhensible
> Vous dites « Nous avons préparé la salle avant l’ouverture ». À l’écoute, vous pouvez décider d’ajouter votre action précise lors d’un nouvel essai, par exemple « J’ai installé les panneaux et montré à l’équipe où orienter les visiteurs. »

## Lire le retour ou vous réécouter

Lorsque le retour est prêt, « Lire mon retour » ouvre le texte. « Me réécouter » ouvre le lecteur si l’enregistrement est disponible. Les repères vous permettent de retrouver certains passages. Comme vous répondez en voix seule, les repères liés à l’image, par exemple la direction du regard, ne sont pas disponibles pour cet enregistrement.

Choisissez un élément à conserver et un éventuel point à essayer. Par exemple, écoutez si une pause vous aide à séparer deux idées. Vous pouvez regarder [le guide sur les points d’appui et les pistes à explorer](#/ressources/comprendre-son-retour-points-d-appui-et-pistes) pour retrouver les libellés et choisir ce que vous souhaitez travailler.

## Décider de garder ou d’envoyer la réponse

Votre enregistrement reste dans votre espace tant que vous ne décidez pas de l’envoyer ou de le supprimer. Si vous souhaitez demander un avis à votre coach, ouvrez « Envoyer à mon coach », puis vérifiez l'entretien que vous vous apprêtez à envoyer. Vous pouvez ajouter un message qui précise le passage ou l’idée sur laquelle vous souhaitez un avis.

Vous pouvez également garder l'entretien pour votre entraînement. Si vous aviez sélectionné plusieurs questions, utilisez la commande qui vous mène à la question suivante quand vous voulez. Pour préparer un entretien téléphonique, vous pouvez refaire un essai en vous concentrant sur les dates, les noms de tâches et les fins de phrases que votre interlocuteur devra entendre.

> [!a-retenir] Pour vous entraîner en voix seule
> Choisissez « Voix seule », enregistrez un entretien puis réécoutez-le. Vous pouvez recommencer, garder l'entretien ou demander un retour si vous avez activé l’assistant.
